# AGENTS.md — Basket Stats

## Project Overview
Basket Stats is a web application designed for basketball coaches and tactical analysts to manage team statistics, game logs, player performance metrics, and advanced analytics.

## Tech Stack & Architecture
- **Frontend:** React 19, TypeScript, React Router 7, Recharts, Vite
- **Styling:** Plain CSS with CSS Variables (Mobile First design pattern)
- **AI Integration:** Google Gemini API (REST endpoint with System Prompt)

## Code Standards & Conventions
- Single quotes `'` strictly for strings and imports.
- No trailing semicolons `;`.
- No extra spaces inside braces or brackets `import {foo} from 'bar'`.
- Mobile First responsive interfaces.

## AI Assistant Role & Context
- **Role:** Tactical Basketball Assistant for coaches.
- **Tone:** Professional, direct, analytical, and encouraging.
- **Scope:** Provide tactical insights, player comparison, game recaps, and usage advice for the Basket Stats app.
